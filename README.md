# bin2

**Files that never die.**

Every year, millions of files stop opening. The app that made them is gone, the format is forgotten, or the new computer simply can't read them. Old documents, photos from a phone that no longer exists, a project file from fifteen years ago.

bin2 fixes that. It seals any file together with its own viewer, so the file carries everything it needs to open, anywhere, for as long as it exists.

## What bin2 does

- **Seal any file.** A photo, a PDF, a song, a document, a game save. bin2 turns it into a single `.bin2` file.
- **Open it anywhere.** A `.bin2` opens in the bin2 app. On a device without bin2, it still opens in any ordinary web browser, offline.
- **Keep the original, untouched.** The exact original file is stored inside, byte for byte, and can always be taken back out.
- **Know it's intact.** Every `.bin2` carries a fingerprint of the original and checks itself each time it opens.
- **Never get locked in.** Even with no software at all, a `.bin2` explains in plain words how to recover what's inside.

## Why it matters

| Without bin2 | With bin2 |
|---|---|
| A file needs the right app to open | The file brings its own viewer |
| Formats die and files die with them | The viewer travels inside the file |
| Damage goes unnoticed | Every open checks integrity |
| Recovering old files needs experts | Recovery instructions are built in |

## Status

bin2 is in early development.

- **Working now:** sealing and recovering any file, with viewers for common images, PDF, audio, video, text and Markdown. On Windows, bin2 adds "Seal with bin2" to the right-click menu, and `.bin2` files open with a double-click.
- **Next:** a full desktop app, and viewers for HEIC photos, camera RAW, Photoshop and Word documents.
- **Later:** viewers for long-dead document formats, and emulation for old programs and games.

## The name

bin2 reads as "bin to": turning a file into something that lasts.
